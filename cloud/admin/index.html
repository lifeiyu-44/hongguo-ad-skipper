QQ 邮箱授权码怎么拿：
1. 电脑浏览器打开 mail.qq.com → 右上角「设置」→「账户」标签
2. 页面下拉到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
3. 开启「IMAP/SMTP服务」→ 按弹窗提示用绑定手机发短信 → 得到 16 位授权码

配置保存后立即生效、无需重启；授权码只保存在服务器上（权限 600），此处不回显。
