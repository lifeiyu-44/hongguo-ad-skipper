# 红果广告跳过（HongguoAdSkipper）

一个安卓小工具：在「红果短剧 / 红果免费短剧」看剧时，自动**识别插播广告**和**「N秒后可继续上滑观看短剧」倒计时**，倒计时一结束就**自动上滑进入下一集**，不用再盯着屏幕等广告。

> 全部识别基于无障碍服务读取的屏幕文字，在本机完成，**不联网、不上传任何数据**。

## 工作原理

1. 通过 **无障碍服务（AccessibilityService）** 轮询前台窗口，判断当前是否为红果短剧（包名 `com.phoenix.read`）。
2. 遍历当前界面的视图树，匹配三类广告特征文字（均只认屏幕内可见的节点）：
   - 底部提示：`3秒后可继续上滑观看短剧`（倒计时主特征，正则见 `AdSkipService.kt` 顶部 `COUNTDOWN_REGEX`）
   - 右上角「广告」角标（含 `广告 15s` 这类带单位的剩余秒数）
   - 直播购物类广告特征：`直播中` / `讲解中` / `已售N件`（这类广告无角标无倒计时）
3. 检测到倒计时后记录截止时间，并用屏幕上不断刷新的秒数持续校正。
4. 倒计时归零 → 模拟一次**上滑手势**（`dispatchGesture`）翻到下一集；如果界面里有「跳过」按钮则优先点击。
5. 上滑后进入 2.6 秒冷却期，避免误触下一集。

附加能力：

- **零干扰**：播放时屏幕上不显示任何悬浮内容、边框或提示；识别与跳过全程在后台进行，过程记录在 App 的日志页。
- **断网保护**：设备没有网络时自动暂停识别与上滑（避免把断网页面误判成广告），联网后自动恢复，日志中有记录。
- **自动学习监测应用**：如果在其他 App 里发现同款倒计时文案，会自动把该包名加入监测列表。
- **运行日志 + 累计跳过计数**，主界面可随时查看。
- **测试上滑按钮**：一键验证手势在你设备上是否有效。

## 平板适配

- 上滑手势坐标**按屏幕宽高比例计算**，手机竖屏、平板竖屏、平板横屏都适用；
- 主界面布局限宽 620dp 居中，平板大屏两侧留白不拉伸，横竖屏均可使用；
- 悬浮窗按屏幕高度比例定位，横竖屏切换不会遮挡内容；
- 服务状态保存在进程级状态流中，旋转屏幕不丢状态。

## 构建 APK

### 方式一：Android Studio（推荐）

1. 用 Android Studio（Hedgehog 或更新版本）打开本项目根目录；
2. 等待 Gradle Sync 完成（首次需联网下载依赖）；
3. 菜单 `Build → Build Bundle(s) / APK(s) → Build APK(s)`；
4. 产物在 `app/build/outputs/apk/debug/app-debug.apk`。

### 方式二：命令行

```bash
# 需要 JDK 17，以及 local.properties 指定 sdk.dir（Android Studio 打开一次会自动生成）
./gradlew assembleDebug        # Windows 用 gradlew.bat assembleDebug
```

## 使用步骤

1. 安装并打开本 App；
2. 点「**去开启无障碍服务**」→ 找到「红果短剧广告自动上滑」→ 开启；
   - **Android 13+** 若提示「受限设置」：先在 系统设置 → 应用 → 本 App → 右上角菜单 → **允许受限设置**，再回无障碍设置开启；
3. 点「**打开红果短剧**」正常追剧即可。广告到点自动上滑，屏幕上不会出现任何提示；
4. 首次使用建议在主界面点「**测试上滑**」确认手势有效。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 断网时它不动 | 正常保护机制：无网络时暂停识别与上滑，联网后自动恢复（日志里会记录） |
| 广告出现了但没反应 | 红果短剧更新后文案可能变化：修改 `AdSkipService.kt` 顶部的 `COUNTDOWN_REGEX` 适配新文案；日志页可确认是否识别到 |
| 上滑没翻页 | 在设置里把「延迟上滑毫秒数」调大一点（如 500ms）；或用「测试上滑」验证 |
| 识别到别的 App | 点「重置监测应用」恢复默认，或关闭「自动跳过广告」总开关 |
| 服务被杀 | 在系统设置里给本 App 关闭省电策略/加自启动白名单 |
